How to use this tool
An AI reference assistant — not a replacement

Trained on VAG technical data, this tool accelerates your diagnostic workflow by aggregating common knowledge from multiple sources. It does not replace ElsaPro, ODIS, or hands-on inspection.

📊
Reading the CONFIDENCE rating

Every response ends with a confidence self-assessment:

  • HIGH
    Cross-referenced from multiple verified sources. Safe to act on.
  • MEDIUM
    General technical reasoning. Verify before ordering parts.
  • LOW
    Speculative or incomplete data. Always verify with ElsaPro.
⚠
The "VERIFY" flag

When you see ⚠ VERIFY: [something] in a response, the AI is uncertain about that specific detail. Cross-check against ElsaPro before acting on those points.

✅
Best practices
  • Use VIN when possible — auto-decodes year/model/engine
  • Be specific — "P0299 above 3000 rpm WOT" beats "P0299"
  • Group symptoms — "P0299 + rough idle + cold start"
  • Confirm engine code — the tool flags VIN/model conflicts
  • Cross-check VCDS live data — never replace direct measurement
🚫
What NOT to use it for
  • Final repair authorization without ElsaPro confirmation
  • Specific torque specs or fluid capacities — verify by VIN
  • Wiring diagrams or pin assignments — refer to official docs
  • Recall/TSB confirmation — check VW/Audi Canada portal with VIN
💡
When the AI gets it wrong

The AI can make mistakes, especially on rare engines or post-2024 models. If a response seems off:

  • Check the CONFIDENCE rating — LOW means trust it less
  • Look for ⚠ VERIFY flags
  • Re-run with more specific context (engine code, VIN)
  • Report wrong answers to astroracinggear@gmail.com
📈
Continuous improvement

An automated bot validates this tool daily against known VAG cases. Errors are tracked and the system is refined weekly. Your feedback accelerates this.

Un assistant de référence IA — pas un substitut

Formé sur des données techniques VAG, cet outil accélère votre flux diagnostique en agrégeant des connaissances de multiples sources. Il ne remplace pas ElsaPro, ODIS, ou une inspection en personne.

📊
Lire l'indice de CONFIANCE

Chaque réponse se termine par une auto-évaluation de confiance :

  • HIGH
    Recoupé de plusieurs sources vérifiées. Sécuritaire d'agir.
  • MEDIUM
    Raisonnement technique général. Vérifiez avant de commander.
  • LOW
    Données spéculatives ou incomplètes. Toujours vérifier avec ElsaPro.
⚠
Le marqueur "VERIFY"

Quand vous voyez ⚠ VERIFY: [élément], l'IA n'est pas certaine de ce détail. Recoupez avec ElsaPro avant d'agir sur ces points.

✅
Bonnes pratiques
  • Utilisez le VIN — décode année/modèle/moteur automatiquement
  • Soyez spécifique — "P0299 au-dessus de 3000 rpm WOT" vaut mieux que "P0299"
  • Groupez les symptômes — "P0299 + ralenti instable + démarrage à froid"
  • Confirmez le code moteur — l'outil signale les conflits VIN/modèle
  • Recoupez les données VCDS live — ne remplacez jamais une mesure directe
🚫
Ce pour quoi NE PAS l'utiliser
  • Autorisation finale de réparation sans confirmation ElsaPro
  • Spécifications de couple ou capacités de fluides — vérifier par VIN
  • Schémas électriques ou affectations de broches — docs officielles
  • Confirmation de rappel/TSB — portail VW/Audi Canada avec le VIN
💡
Quand l'IA se trompe

L'IA peut faire des erreurs, surtout sur des moteurs rares ou modèles post-2024. Si une réponse semble étrange :

  • Regardez l'indice CONFIDENCE — LOW signifie moins de confiance
  • Cherchez les marqueurs ⚠ VERIFY
  • Relancez avec plus de contexte (code moteur, VIN)
  • Signalez les erreurs à astroracinggear@gmail.com
